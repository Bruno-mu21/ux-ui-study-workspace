### 📝 Case Study: Estrutura & Exemplos
- **Template Notion (Grátis):** Busque "UX Case Study Template Notion" (ex: *Juliano Lima*, *Rocketseat*, *Designer Up*).
- **Exemplos Reais (Behance/Dribbble):** Busque por **"UX Case Study Mobile App"** ou **"Product Design Case Study"**. Analise a estrutura: *Problema → Research → IA → Wireframes → UI System → Prototype → Testes → Métricas/Próximos Passos*.
- **Storytelling:** [Artigo "Storytelling no Portfólio UX"](https://medium.com/design-ibm/storytelling-no-portf%C3%B3lio-de-ux-5d8b8e8f8b8e)

### ✅ Checklist de Entrega DIO (Baseado no Módulo "Como Entregar")
- [ ] Link do **Protótipo Figma** (Config: *Anyone with link can view* + *Prototype mode* ativo).
- [ ] Link do **Case Study** (Notion Público / PDF / Behance / Site Próprio).
- [ ] **Vídeo Demo** (1-2 min, narrado ou com legendas, mostrando fluxos principais) — *Verificar se obrigatório no edital atual.*
- [ ] **README / Descrição** no formulário de submissão (Problema, Solução, Stack, Link Figma, Link Case).
- [ ] **Prints/Artefatos** complementares (Wireframes, Design System, User Flows) se solicitados.
